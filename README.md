# Tulas International School — Homepage Redesign

A responsive React homepage inspired by the real Tulas International School website. It preserves the school's public-facing information and homepage flow while using replacement campus and student-life photography.

## Tech Stack

- React 19
- Vite
- CSS
- Intersection Observer and CSS animations

## Features

- Responsive navigation with a mobile menu
- Campus-led hero and validated enquiry form
- TIS story, CBSE academics, sports, campus highlights and rankings
- Campus visitors, parent testimonials and collaboration feature
- Admissions CTA, contact details, Google Maps embed and responsive footer
- Scroll-triggered reveals and a scroll progress indicator
- Reduced-motion support, semantic headings and image alt text
